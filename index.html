Master System and Game Gear BIOS

None is needed: games start as the BIOS would leave them. With one, the console starts in it as the real one does: it shows its logo, checks the game, and starts it. The BIOS ROMs are still under copyright, so none is included here: choose or drop your own BIOS image file. Yours stay in this browser and are never sent anywhere.

  • Master System BIOS Optional

    8K or more: the plain ones are 8K, those with a game built in bigger. Export Master System BIOSes refuse games without a valid Sega header, as on the real console. A Master System with a BIOS also switches on with no cartridge in.

    Often named bios.sms or [BIOS] Sega Master System (USA, Europe) (v1.3).sms

  • Game Gear BIOS Optional

    Exactly 1K (1,024 bytes).

    Often named bios.gg

The retrobios collection keeps bios.sms in its Master System folder and bios.gg in its Game Gear folder.
